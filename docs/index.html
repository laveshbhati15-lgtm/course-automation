Standalone & Local Automation CLI

CodeChef Course Automation & Progress Inspector

A lightweight, portable open-source CLI tool for inspecting course progress, reading theory concepts, and assisting with coursework on CodeChef Learn. Runs completely on your local machine using standard Python and Playwright.

Created by Lavesh Bhati
Get Started View on GitHub

What the Project Does

Course Automation is designed to run locally from your terminal, connecting to your authenticated CodeChef Learn session via Playwright without requiring browser extensions or cloud daemons:

1

Inspect Course Structure

Dynamically discovers modules, theory lessons, quizzes, and coding exercises from any valid CodeChef Learn course URL or active browser tab.

2

Read Theory Concepts

Smoothly scrolls through reading lessons to trigger dynamic rendering (MathJax and code snippets) and advances using accessible navigation controls.

3

Assist with Quizzes (MCQs)

Extracts questions and choices, evaluates answers using heuristic matching or optional AI reasoning, and requires human confirmation before submitting.

4

Assist with Coding Labs

Injects solutions into Monaco and Ace code editors across C++, Java, C, and Python using base64 buffer injection to prevent quotation or newline corruption.

5

Track Offline Progress

Maintains a local SQLite database of course syllabi, module breakdowns, and completion metrics without requiring an active browser connection.

6

Safety by Default

Provides a non-mutating --dry-run mode to simulate operations without submitting, plus regex filters to redact credentials from all logs.

Features & Known Limitations

Core Features

  • Dynamic Course Discovery: Operates on any valid CodeChef Learn course URL; nothing is hardcoded to a specific subject.
  • Active Tab Auto-Detection: Detects which course tab is currently open in your browser session if no URL is passed.
  • Zero-Mutation Dry-Run: Full simulation mode (--dry-run) to inspect pages, read content, and reason about questions without clicking submit or altering course progress.
  • Interactive Confirmation: Prompts for terminal approval before any live submission unless --auto-approve is explicitly passed.
  • Credential Redaction: Automatically scrubs API keys, session tokens, and passwords from console output and log files.

Known Limitations

Scope & Platform Limitations

Locked Activities (LOCKED_SKIPPED): Activities locked by prerequisite gates or scheduling deadlines are recognized honestly and skipped; they are never bypassed.

Proctored Exams: Proctored tests, webcam-monitored exams, or lockdown browser assessments are completely unsupported.

CAPTCHAs / Bot Challenges: Rare Cloudflare or CAPTCHA challenges require manual completion in the headful browser window.

Supported Sites: Only CodeChef Learn is currently implemented.

Supported Operating Systems & Python Versions

Python Compatibility

The project requires Python 3.10 or newer (modern union type syntax A | B is used throughout the codebase):

  • Python 3.10, 3.11, 3.12: Supported and tested.
  • Python 3.14: Tested and verified in local clean test environments.
  • Python 3.9 and older: Not supported.

Operating System Matrix

Operating System Status Verification Notes
macOS (Apple Silicon & Intel) Verified Fully tested and verified on macOS Darwin with Python 3.12 and 3.14.
Linux (Ubuntu, Debian, Fedora) Supported Standard POSIX Python and Playwright environments.
Windows 10 / Windows 11 Unverified on Host Architecturally supported; instructions below use standard PowerShell workflows. Must be validated on a physical Windows machine.

Quick Start Installation

Choose your operating system below for complete copy-paste setup instructions:

Step 1: Install Prerequisites (Homebrew)

bash 
brew install python git

Step 2: Clone & Enter Repository

bash 
git clone https://github.com/laveshbhati15-lgtm/course-automation.git
cd course-automation

Step 3: Create & Activate Virtual Environment

bash 
python3 -m venv .venv
source .venv/bin/activate

Step 4: Upgrade Pip & Install Project

bash 
python3 -m pip install --upgrade pip
pip install -e .

Step 5: Install Playwright Chromium Browser

bash 
playwright install chromium

Step 6: Verify CLI

bash 
course-automation --help
course-automation config
Windows Prerequisites

Install Python 3.10-3.12 from python.org (Ensure "Add python.exe to PATH" is checked) and Git for Windows from git-scm.com.

Step 1: Clone Repository in PowerShell

powershell 
git clone https://github.com/laveshbhati15-lgtm/course-automation.git
cd course-automation

Step 2: Create Virtual Environment

powershell 
python -m venv .venv

Step 3: Activate Safely (Bypassing Script Restrictions for this Session)

powershell 
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
.venv\Scripts\Activate.ps1

Step 4: Upgrade Pip & Install Dependencies

powershell 
python -m pip install --upgrade pip
pip install -e .

Step 5: Install Playwright Chromium Browser

powershell 
playwright install chromium

Step 6: Verify Installation

powershell 
course-automation --help
course-automation config

Package Installation Commands Reference

The project relies strictly on standard Python packaging specified in pyproject.toml:

Command Target Package / Extra When to Use
pip install -e . Base Project & Runtime Standard installation for users (Playwright, Typer, Rich, Pydantic, Requests, Dotenv).
pip install -e ".[dev]" Development & Testing For developers and running the 67 automated tests (includes pytest, pytest-mock, google-genai).
pip install -e ".[ai]" Optional AI Reasoning Installs Google Gemini SDK (google-genai) for MCQ reasoning assistance.
playwright install chromium Browser Binaries Downloads the standalone Chromium browser binary required by Playwright.

Authentication & Browser Session Handling

Course Automation uses a persistent local browser profile to maintain your logged-in state without storing your plaintext username or password.

One-Time Login Command

bash 
course-automation auth
  1. A headful Chromium window opens to the CodeChef login page.
  2. Log in manually via your preferred provider (Email/Password, Google OAuth, GitHub).
  3. The CLI detects successful login, caches cookies, and exits cleanly.
Session Storage Security Notice (No Application Encryption)

Browser cookies and session state are saved locally inside ~/.course_automation/browser_profile (or %USERPROFILE%\.course_automation\browser_profile on Windows) in standard Chromium directory format.

They are NOT encrypted at rest by the application. Session privacy is protected strictly by your operating system user account filesystem permissions. Never share or commit your .course_automation folder to version control.

Configuration & Optional AI Setup

Course Automation is 100% functional without an AI provider (default: AI_PROVIDER=none) for syllabus inspection, reading theory lessons, and tracking progress.

Enabling Google Gemini for MCQ Reasoning (Optional)

1. Copy the configuration template:

bash
cp .env.example .env

2. Install optional AI dependencies:

bash
pip install -e ".[ai]"

3. Edit .env with your Google AI Studio API key:

env
AI_PROVIDER=gemini
GEMINI_API_KEY=your_google_ai_studio_api_key_here
GEMINI_MODEL=gemini-flash-lite-latest
Google AI Studio Free Tier Notice

Personal developer API keys can be generated at Google AI Studio. The gemini-flash-lite-latest model is eligible for Google's developer free tier. Disclaimer: API availability, quotas, and rate limits are governed by Google. The project does not guarantee unlimited or perpetual free access.

CLI Usage & Examples

1. Inspect Any Course Syllabus

Displays all units, module names, activity counts, and completion percentages:

bash
course-automation inspect https://www.codechef.com/learn/course/cu-oops-sem3-2026-c2

Tip: If you already have the course open in your browser, omit the URL to auto-detect the active tab:

bash
course-automation inspect

2. Filter Only Incomplete Activities

bash
course-automation inspect https://www.codechef.com/learn/course/cu-oops-sem3-2026-c2 --incomplete-only

3. Interactively Select a Specific Module

bash
course-automation inspect https://www.codechef.com/learn/course/cu-oops-sem3-2026-c2 --select-module

4. Safe Dry-Run Simulation (Recommended First Run)

bash
course-automation solve https://www.codechef.com/learn/course/cu-oops-sem3-2026-c2 --dry-run

5. Assisted Reading & Quizzes (Interactive Confirmation)

bash
course-automation solve https://www.codechef.com/learn/course/cu-oops-sem3-2026-c2 --theory-only --max-activities 5

6. View Offline SQLite Progress Summary

bash
course-automation status

Safe Dry-Run Testing

The --dry-run flag is an intentional safety feature designed to protect your account and course progress:

Theory Reading Lessons

Scrolls down the page to trigger dynamic MathJax rendering and code formatting, verifies that the Next/Continue button is enabled, but does not click it.

Quizzes (MCQs)

Extracts the question stem and all multiple-choice options, evaluates reasoning, but never clicks any radio button or submits the answer.

Coding Exercises

Detects the problem statement, active language, and starter code without clicking Run or submitting code to the grading queue.

Troubleshooting Guide

Click any common issue below for immediate resolution steps:

The Playwright Chromium browser binary has not been installed yet. Run:

bash
playwright install chromium

Your CodeChef session cookies have expired. Re-authenticate using the headful browser:

bash
course-automation auth

Do NOT disable system security globally. Instead, grant script permissions only to the current PowerShell process:

powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
.venv\Scripts\Activate.ps1

Python was installed without adding it to the system PATH. You can use the Windows Python launcher instead:

powershell
py -3 -m venv .venv

Or reinstall Python from python.org and check "Add python.exe to PATH".

If you see Protocol error (Browser.setDownloadBehavior), leave BROWSER_CDP_URL= empty in your .env file. The tool will automatically use its standalone persistent browser profile.

In your .env file, update GEMINI_MODEL to an active model:

env
GEMINI_MODEL=gemini-flash-lite-latest

Running Automated Tests

All 67 tests in the test suite run 100% offline using synthetic mocks and isolated local databases:

bash
pip install -e ".[dev]"
pytest -v
Testing Rule for Contributors

Never run automated tests against live personal courses or user accounts. In particular, never use completed or active courses (such as DBMS cu-dbms-sem3-2026-c2) as a test target. All tests must be validated using mocked DOM pages, synthetic fixtures, and local database instances.
